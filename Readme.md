# Django MySQL Student Ride Sharing App

The world of tech definitely don't need another Ride sharing app but for my CSE370 project I created one anyway.
Six days of non-stop coding, minimal sleep, and endless cups of homemade Iced Tea later, here it is!
Stuber is a student ride sharing app developed to aid students looking for a safer way to get rides and share too. This app demands the users to have an G-Suite account which is verified by sending a token with a link. Currently the app accepts only BRACU emails, however, this is scalable to add other universities. Users can apply to become host and host rides or simply just request rides for other hosts to accept. Host’s themselves can also schedule rides for a later time, which users can book. Everyone has their own profile with ride history and derived rating.
LocationIQ API is used to autocomplete and get distance data. (since I don't have a Passport endorsed Credit/Debit card needed to get the Google APIs)
